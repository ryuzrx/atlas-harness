# Atlas website

The site is a dependency-free static page. To preview it from the repository root:

```bash
python3 -m http.server 4173 --directory website
```

Open `http://127.0.0.1:4173`. The screenshots in `assets/` are captured from Atlas in its dark theme, using a separate data folder with a fictional Demo profile, sample project and demo teams. No real conversations or files appear in them. The download links point to the latest Apple Silicon release.
