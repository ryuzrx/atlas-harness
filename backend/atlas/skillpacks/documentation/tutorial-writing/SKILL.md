Use this to write a step-by-step tutorial.

## Steps
1. State who it's for, what they'll build or learn, the prerequisites, and how long it takes.
2. Show the end result first.
3. Use numbered steps, one action each, with the exact command or code and the expected result.
4. Explain why briefly, after the step works, not before.
5. Add checkpoints ("you should now see…") and common errors with fixes.
6. End with a recap and next steps. Test the whole thing from a clean start.

## Output
The tutorial in Markdown, with code blocks and expected outputs.
