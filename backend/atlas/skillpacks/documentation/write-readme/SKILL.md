Use this to write a README people actually use.

## Steps
1. Name, one sentence on what it is, and who it's for. Add a screenshot or demo if it's visual.
2. Quick start: install and run in the fewest commands, copy-pasteable.
3. Usage: the 2 or 3 most common tasks, with examples.
4. Configuration: environment variables and options in a table.
5. Development: how to set up, test and contribute.
6. Licence, support and links.

## Watch out for
- Walls of text before the quick start.
- Commands that only work on the author's machine.

## Output
The README.md.
