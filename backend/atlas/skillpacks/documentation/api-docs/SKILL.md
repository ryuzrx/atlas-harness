Use this to document an API.

## Steps
1. Overview: what the API does, the base URL, how to authenticate, rate limits and versioning.
2. A quick start: get a key and make a first successful call in under 5 minutes, with a copy-paste example.
3. For each endpoint: method and path, purpose, parameters (type, required, default), request example, response example, and errors.
4. Error reference: codes, what they mean, and how to fix them.
5. Guides for common tasks, which may combine several endpoints.
6. Keep it in sync with the code: generate from OpenAPI where you can.

## Output
The docs in Markdown or as an OpenAPI file, with tested examples.
