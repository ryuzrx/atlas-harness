Use this to plan and build a landing page that converts.

## Steps
1. Settle the one audience, the one action you want (sign up, buy, download) and the one main promise.
2. Structure: hero (a headline that states the benefit, a supporting line, the main button, a visual), social proof, 3 or 4 benefits with specifics, how it works, pricing or FAQ, then a repeated call to action.
3. Write the copy before the design. Lead with the benefit, use plain words, and keep the headline under about 10 words.
4. Build it with semantic HTML, responsive from mobile up, and fast: optimised images, little JavaScript, fonts with `font-display: swap`.
5. Add the basics: title and meta description, Open Graph tags, a favicon, analytics for the main action, and accessible contrast and labels.

## Output
The page outline with copy, then the code in the project's stack, plus a short checklist of what to test.
