Use this to improve how a page shows up in search.

## Steps
1. Match the page to one main search intent and query.
2. Write a title tag of about 50 to 60 characters that includes the main term, and a meta description of about 150 to 160 characters that would make someone click.
3. Use one H1, a logical H2 and H3 structure, and content that actually answers the query.
4. Use clean URLs, a canonical tag, internal links with descriptive text, and alt text on images.
5. Technical basics: fast loading, works on mobile, indexable (no stray `noindex`), sitemap and robots.txt, and structured data where it fits.

## Watch out for
- Keyword stuffing.
- Thin duplicate pages.

## Output
The specific changes (current → suggested) for title, meta, headings, content gaps and technical issues.
