---
name: microcopy
description: Write short, clear interface text.
---

Use this to write buttons, labels, errors, empty states and tooltips.

## Steps
1. Write from the user's side of the screen: what they want, not how the system works.
2. Buttons: use a verb that says what will happen ("Save changes", "Delete project"), not "OK" or "Submit".
3. Errors: say what went wrong and how to fix it, without blame ("That email is already used. Sign in instead?").
4. Empty states: say why it's empty and give the one next step.
5. Keep it short, but complete. Use the same word for the same thing everywhere.
6. Use sentence case, a friendly tone, and no jargon or internal names.

## Output
A table of each element: where it appears, the current text, the new text, and why it's better.
