Use this to review a screen for clarity and polish.

## Steps
1. Five-second test: what is this screen for, and what's the main action? If that isn't obvious, it's the top issue.
2. Hierarchy: one clear primary action, secondary actions quieter, related things grouped.
3. Layout: consistent spacing scale, alignment, sensible line lengths, nothing cramped or floating.
4. States: loading, empty, error, success, long text, and many items versus one.
5. Consistency with the rest of the app: components, icons, wording and colours.
6. Responsiveness and both themes.

## Output
A ranked list of issues, each with a screenshot reference or location, why it matters, and the fix. Quick wins are marked.
