---
name: user-flow
description: Map a user journey and find friction.
---

Use this to map how a user gets something done and find the friction.

## Steps
1. Name the user, their goal and their starting point.
2. List every step: screen, action, system response and decision point.
3. Mark the friction: extra steps, unclear choices, waiting, dead ends, errors and places where users must remember things.
4. Note what happens off the happy path: they go back, cancel, hit an error, or come back later.
5. Suggest a shorter flow: remove, merge or reorder steps, use smart defaults, or delay optional choices.

## Output
The current flow as a numbered list (or a Mermaid diagram), the friction points, and the proposed flow with the steps saved.
