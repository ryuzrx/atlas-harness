Use this to choose a chart and make it readable.

## Steps
1. Name the message first ("sales doubled in Q3"), then pick the chart that shows it.
2. Choose the type: change over time → line; compare categories → bar (sorted); part of a whole → stacked bar (a pie only for 2 or 3 parts); relationship → scatter; distribution → histogram or box plot.
3. Start bar axes at zero. Label the axes with units. Label lines directly instead of using a legend where you can.
4. Use colour sparingly: grey for context and one accent colour for the point. Make sure it works for colour-blind readers.
5. Write a title that states the takeaway.

## Output
The recommended chart, why it fits, and the design settings, plus code if a tool was named.
