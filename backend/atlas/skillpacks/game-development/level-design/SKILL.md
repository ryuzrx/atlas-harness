Use this to design an engaging level.

## Steps
1. Give the level one main idea: a new mechanic, a twist on an old one, or a test of mastery.
2. Teach the idea safely, then test it, then twist it. Raise the challenge gradually and add rest beats.
3. Guide the player with light, landmarks, lines of sight and composition, not arrows everywhere.
4. Reward exploration with optional secrets. Keep the main path clear.
5. Place checkpoints so a failure doesn't cost too much progress.
6. Grey-box it first, playtest, then add art.

## Output
The level goal, a beat-by-beat flow, a layout sketch description, and playtest questions.
