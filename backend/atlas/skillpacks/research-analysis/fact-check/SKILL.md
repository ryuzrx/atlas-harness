---
name: fact-check
description: Check claims against evidence.
---

Use this to check whether claims are true.

## Steps
1. Pull out each checkable claim on its own line. Skip opinions.
2. For each claim, find the original source of the fact, not a repost.
3. Check the details: numbers, dates, names, quote wording, and whether the context changes the meaning.
4. Give a rating: True, Mostly true, Misleading, False or Unverifiable.
5. Give a one-line reason and the source for each rating.

## Watch out for
- Confirming a claim because many sites repeat it. They often copy each other.
- Ignoring the date. Something true in 2019 may be false today.

## Output
A table with columns: claim, rating, reason, source. Then a one-paragraph overall verdict.
