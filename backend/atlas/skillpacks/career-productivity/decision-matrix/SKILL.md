Use this to decide between options.

## Steps
1. State the decision and the options, including "wait" or "neither" if those are real.
2. Choose the criteria that matter and weight them (adding to 100%) before scoring.
3. Score each option from 1 to 5 on each criterion, with a one-line reason.
4. Multiply and add up. Then sanity-check: does the winner feel right? If not, a criterion or weight is missing.
5. Note the deal-breakers, how reversible each choice is, and the cheapest way to test before committing.

## Output
The matrix table, the result, a gut check, and a recommendation.
